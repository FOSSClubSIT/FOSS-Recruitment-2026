# wal-pyroclear

A basic template and tutorial to use colors generated by [pywal16](https://github.com/eylles/pywal16) in [pyroclear](https://github.com/shreyanth-sureshkrishnaa/pyroclear)

https://github.com/user-attachments/assets/067e10cd-6673-4ff6-a7b6-4d98dc920756

## Requirements

**1. Pywal and pyroclear should be installed**, you can refer the links given above to install respective software, you can also use `which wal` and `which pyroclear` to confirm if they are installed. If they are installed the commands will return the directory of their executable such as `~/.local/bin/wal`

**2. A text editor (Optional)**, required if you want to change starting and ending colors used to generate the gradient for pyroclear 

## How to install 

- Run the following in the terminal to install the template.

```
git clone https://github.com/Granth9923/FOSS-Recruitment-2026
cd FOSS-Recruitment-2026/granth_bhavsar/
chmod +x install.sh
./install.sh
```

- Add the following to your pywal postrun script, a postrun script is a script that runs after pywal has completed generating colors.

```
cp ~/.cache/wal/custom_palettes.toml ~/.config/pyroclear/custom_palettes.toml
pyroclear --color pywal 
```

or run the following in the `granth_bhavsar` directory

```
chmod +x postrun.sh
./postrun.sh
```

 - **Tip:** A postrun script can be executed automatically using the `-o` flag in pywal.

## How to change gradient

- open `custom_palettes.toml` in the templates folder in a text editor and chage the color values in front of from and to, to the desired colors. For example `{color10}`, current system colors can be viewed with `wal --preview`. Here note that the index for the colors starts from `0` hence the color in the top left will be `{color0}` and continues towards the right. Run install.sh again after making the changes with `./install.sh`

## Anything that I found hard or would do differently

I did not find anthing particularly hard in this project as it was a rather simple one, I was intending to use multiple colors for pyroclear but after looking into `custom_palettes.toml`, I found out that it only takes the start and end color hex codes and generates the rest of the gradient by itself.
