The Underboss is a crime simulator discord bot, where you run your own crime syndicate.
There are 2 main stats currently, your cash balance and manpower.
As of now, you can earn cash through mugging and extorting, and then buy manpower through that cash.
Use !help to get a list of available commands for the bot.

One thing I would do differently if I had more time would be using a real database instead of a python dictionary, and I'd add way more stats such as respect, territories, properties, rivals, alliances, turf wars, etc.
