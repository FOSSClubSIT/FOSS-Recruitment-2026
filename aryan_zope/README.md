## Overview

Bhaav is a farmer-centric price discovery platform that provides real-time mandi (market) prices and actionable insights to help farmers make informed selling decisions. The platform addresses the critical challenge of market information asymmetry faced by agricultural producers.

### Key Features

- **Live Market Prices**: Daily mandi prices sorted by best rates for selected crops
- **Price Trends**: 7-day historical trend visualization for optimal markets
- **Smart Recommendations**: Plain-language "sell now / wait" guidance based on price movement analysis
- **Multi-market Comparison**: Compare prices across different mandis and districts
