# TicTacToe Game
Just a simple tic-tac-toe game written in Java
It is a 2 player game and currently there is no computer mode. The users have to manually click the square. I know this is a very simple project but I have enough knowledge to create it myself without anyone assisting unless I forget the method or some syntax (which can be searched easily). If you find anything not worthy enough for pull request just let me know.

## For running 
The user has to use command 
```java Main.java```

If you face any errors just run `java --version` to check whether java is installed on your system or not.

## Problems Faced
Using the `java.awt` library is hectic enough. Creating GUI is also difficult and currently I am not very good at it but learning constantly.
Other thing is after every move I have to constantly check whether someone has won or not and checking conditions are so repeatitive. Well, honestly speaking I would like to do this conditon checking in some other way but currently I didn't have sufficient knowledge or some interesting idea.  

## Tips
I created this project on my display, so maybe the dimensions may malfunction or the colours may be inappropriate. In that case, open the file and edit the values in `TicTacToe()` constructor. Also, I have not tested in other operating systems other than Linux, although it should work in any system where Java is installed. I have tested the project in Hyprland so it doesn't necessarily need to have buttons for closing, minimizing, etc. but I configured it as far as I can.
